# Aegis Safety Website

A professional static website for Aegis Safety, designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `aegis-safety`).
2. Upload `index.html`, `styles.css`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`, then save.
6. GitHub will provide your live website URL.

## Before publishing

Replace `hello@aegissafety.ca` in `index.html` with your real business email.

The contact form uses `mailto:` so it does not require a server. For a true website form that works without opening the visitor's email application, connect a form service later (such as Formspree or a similar provider).

## Custom domain

If you own a domain, GitHub Pages can be configured to use it from **Settings → Pages → Custom domain**.

## Notes

This site is intentionally static: HTML + CSS + a tiny amount of JavaScript. It is fast, inexpensive to host, and easy to edit.
