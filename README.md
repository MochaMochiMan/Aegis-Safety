## Publish with GitHub Pages
1. Download and extract this ZIP.
2. Create a new GitHub repository, e.g. `aegis-safety`.
3. Upload all files and the `assets` folder to the repository root, preserving the folder structure.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Visit the published URL shown in GitHub Pages settings.

## Contact form
The form is wired to the supplied Formspree endpoint using a POST request. To receive submissions, make sure this endpoint is active in your Formspree account and that its recipient email is set to Aegis.Safety.Contracts@gmail.com. Submit a test enquiry after publishing. Formspree's official setup guide: https://formspree.io/html/
