# Aegis Safety — Complete Website

Upload the files in this package directly to a new GitHub repository. No previous version is required.

## Included
- Premium responsive website with animated sections and custom SVG shield logo
- Services, qualifications, approach, FAQ, and free-quote messaging
- Contact form connected to `https://formspree.io/f/mnpjdold`
- Contact email: `Aegis.Safety.Contracts@gmail.com`
- **Construction audit** option in the contact form and a matching service card/FAQ
- Downloadable illustrative sample safety-review report PDF

## Publish with GitHub Pages
1. Extract the ZIP.
2. Create a GitHub repository, for example `aegis-safety`.
3. Upload all files and the `assets` folder to the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Open the URL shown by GitHub Pages.

## Contact form
The form submits to the provided Formspree endpoint. Ensure the endpoint is active and configured to deliver submissions to `Aegis.Safety.Contracts@gmail.com`, then send a test enquiry after publishing.

## Before publishing
- Verify the exact credential titles and current status with ACSA.
- Pricing is described as free, no-obligation quotes, with costs based on each individual job.
- Add genuine client testimonials only with permission.
- The sample report is fictional and illustrative, not a real review or compliance certification.
- Avoid collecting confidential safety records through the general enquiry form.
